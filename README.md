# Machine Learning - Dell Lead 🤖

Repositório dedicado aos estudos, exercícios práticos e projetos desenvolvidos ao longo do curso de **Machine Learning** promovido pelo programa **Dell Lead**.

---

## 📌 Sobre o Repositório

O objetivo deste repositório é documentar a minha evolução prática na área de Machine Learning, abrangendo desde o pré-processamento de dados até PCA (Principal Component Analysis).

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Python
* **Bibliotecas:** Pandas, NumPy e Matplotlib
* **Ambiente de Desenvolvimento:** PyCharm
* **Controlo de Versão:** Git & GitHub

---

## 📂 Estrutura do Conteúdo

- **`regressao/`**: Exercícios e códigos práticos de modelos de regressão.
  - `regression.py`: Script de estudo sobre algoritmos de regressão.

---

2. **Acesse a psta do projeto:**

   ```bash

4. **Abra e execute no PyCharm:**
